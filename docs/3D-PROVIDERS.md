# 3D: πάροχοι φωτο→3D — πίνακας, άδειες, πρόταση

Γραμμένο 2026-10-31, Κομμάτι 1 της οδηγίας «23. 3D: ΝΕΟ ΕΡΓΑΛΕΙΟ». Έρευνα
σε τρεις παρόχους API (**Meshy**, **Tripo3D**) και ένα ανοιχτό μοντέλο
(**TRELLIS**, Microsoft), πλέον το **`<model-viewer>`** (Google, ανοιχτό)
που θα δείξει το αποτέλεσμα στο Κομμάτι 4. Καμία αλλαγή κώδικα ή βάσης σε
αυτό το κομμάτι — μόνο έρευνα και πρόταση, όπως ζητά η οδηγία.

## Μέθοδος και περιορισμός δικτύου

Το δίκτυο αυτής της δουλειάς μπλόκαρε την απευθείας πρόσβαση σε
`docs.meshy.ai`, `intercom.help`, `tripo3d.ai` και subdomains του,
`replicate.com`, `fal.ai` και `microsoft.github.io` (DNS/CONNECT
μπλοκαρισμένα, επιβεβαιωμένο ως μπλοκάρισμα σε επίπεδο session, όχι
μεμονωμένου παρόχου — το ίδιο έγινε και σε `en.wikipedia.org`). Το
`github.com/microsoft/TRELLIS` (README, LICENSE, issue) και
`raw.githubusercontent.com` (LICENSE αρχεία αυτολεξεί) ήταν προσβάσιμα
απευθείας. Κάθε γραμμή παρακάτω λέει αν προέρχεται από αυτολεξεί αρχείο ή
από απόσπασμα αναζήτησης ιστού· βρέθηκαν όλα **2026-10-31**. Οι γραμμές
«μέσω αναζήτησης» χρειάζονται ζωντανό έλεγχο πριν κλειδώσει αριθμός προς
τον χρήστη — βλέπε «Τι μένει να επιβεβαιωθεί ζωντανά» στο τέλος.

## Η πρόταση: Meshy για Πρόχειρο ΚΑΙ Τελικό, όχι TRELLIS

**TRELLIS αποκλείεται από αυτό το κομμάτι — όχι επειδή η άδειά του εξαιρεί
την ΕΕ (δεν βρέθηκε καμία γεωγραφική εξαίρεση, στην MIT ή στην Nvidia),
αλλά επειδή η δική του εμπορική χρήση είναι ανοιχτό νομικό ερώτημα
σήμερα**: ο κώδικας είναι MIT, αλλά η εξάρτηση rendering που προτείνει το
ίδιο το project (`nvdiffrast`) είναι ρητά μη-εμπορική, και το επίσημο
GitHub issue που ρωτάει ακριβώς αυτό έμεινε αναπάντητο από τη Microsoft.
Μια εφαρμογή που πουλάει μοντέλα 3D σε πελάτες δεν μπορεί να χτιστεί πάνω
σε άδεια που δεν ξέρουμε αν επιτρέπει εμπορική χρήση. Επιπλέον δεν έχει
καμία εγγενή εξαγωγή USDZ/STL και καμία επίσημη τιμή/χρόνο σε πραγματικό
hardware — τριπλός λόγος να μείνει εκτός παραγωγής προς το παρόν. (Αξίζει
δική του γραμμή στο ΘΕΛΩ αν ποτέ θελήσουμε να το ξαναδούμε με νομική
απάντηση στο issue.)

Ανάμεσα σε Meshy και Tripo, προτείνεται **Meshy και για τα δύο επίπεδα**
(Πρόχειρο = χωρίς υφή/φθηνότερο, Τελικό = υφή 8K/ακριβότερο), για τρεις
λόγους αυτολεξεί/επιβεβαιωμένους παραπάνω, όχι εκτίμηση:

1. **Μόνο το Meshy καλύπτει GLB+USDZ+STL εγγενώς**, αυτολεξεί από το
   quick-start του — οι τρεις μορφές που ζητά το πάνελ του Κομματιού 2.
   Το Tripo δεν έχει επιβεβαιωμένη USDZ εξαγωγή· θα χρειαζόταν να
   βασιστούμε στη client-side auto-generation του `<model-viewer>` (βλ.
   κάτω) για το iOS AR, κάτι που δουλεύει αλλά είναι μια έξτρα εξάρτηση.
2. **Το δωρεάν πλάνο του Meshy επιτρέπει εμπορική χρήση με αναφορά** —
   χρήσιμο για δοκιμές πριν δεσμευτούμε σε πληρωμένο πλάνο. Το δωρεάν
   πλάνο καταναλωτή του Tripo λέει αυτολεξεί **«Not granted»** στην
   εμπορική χρήση — θα χρειαζόμασταν πληρωμένο πλάνο εξαρχής.
3. **Ένας πάροχος, μία ενσωμάτωση, μία τιμή να χτυπήσουμε πρώτα.** Ο
   router (Κομμάτι 6 — μπλοκαρισμένο από το stop-gate) μπορεί να πάρει
   δεύτερο πάροχο (Tripo) ως fallback αργότερα χωρίς να ξαναχτιστεί η
   βασική ενσωμάτωση — δεν χάνεται τίποτα κρατώντας το απλό τώρα.

**Κανένας αριθμός εδώ δεν είναι σταθερή τιμή.** Οι δύο επίσημες σελίδες
του Meshy (API vs web app) διαφωνούν μεταξύ τους στο ίδιο τους credits —
ο πραγματικός αριθμός μετριέται στην πρώτη πραγματική κλήση με δικό μας
κλειδί, πριν κλειδώσει τιμή σε credits προς τον χρήστη (όπως λέει και το
`docs/TOOL-RULES.md` για «τιμή πριν»).

## `<model-viewer>` (Google, Apache 2.0) — για το Κομμάτι 4

Αυτολεξεί από το ίδιο το repo (`LICENSE`, README, παράδειγμα AR):

- **Apache 2.0, καμία εμπορική εξαίρεση.**
- **Android → Scene Viewer**: καταναλώνει απευθείας το GLB. **iOS → Quick
  Look**: χρειάζεται USDZ, είτε δοσμένο (`ios-src`) είτε
  **αυτόματα παραγόμενο client-side**, τη στιγμή που ο χρήστης πατάει το
  κουμπί AR σε iPhone — αυτό σημαίνει ότι η USDZ εξαγωγή του ίδιου του
  παρόχου (Meshy την έχει, το Tripo όχι επιβεβαιωμένα) δεν είναι σκληρή
  προϋπόθεση: το `<model-viewer>` μπορεί να καλύψει το κενό μόνος του αν
  χρειαστεί.
- **Καμία επίσημη εγγύηση για μέγεθος αρχείου ή χρόνο φόρτωσης** — το
  «κάτω από 10 MB» και «κάτω από 3 δευτερόλεπτα» της οδηγίας είναι δικές
  μας απαιτήσεις προϊόντος, όχι κάτι που δημοσιεύει το project. Μετριέται
  στο Κομμάτι 4, με τα δικά μας 10 δοκιμαστικά προϊόντα.
- Τεχνικές λεπτομέρειες για το Κομμάτι 4 (όχι τώρα): χρειάζεται
  `"use client"` + φόρτωση μέσα σε `useEffect` ή `next/dynamic({ssr:false})`
  (custom element, δεν αποδίδεται στον server), και μια
  `declare global { namespace JSX { interface IntrinsicElements {
  'model-viewer': any } } }` επέκταση τύπων TypeScript — γνωστά, καλά
  τεκμηριωμένα βήματα, όχι ρίσκο.

## ΘΕΛΩ ΑΠΟ ΤΟΝ ΗΛΙΑ

1. **Κλειδί API Meshy** — για Πρόχειρο (χωρίς υφή, ~20 credits/μοντέλο)
   και Τελικό (υφή 8K, ~35 credits/μοντέλο). Κόστος αρχικό: €0 δοκιμές
   μέσα στο δωρεάν πλάνο (100 credits/μήνα) — πραγματικό κόστος μόνο όταν
   ξεπεράσουμε αυτό το όριο ή χρειαστούμε ιδιωτικά μοντέλα (πληρωμένο
   πλάνο). **Μέχρι να έρθει το κλειδί, το Κομμάτι 3 (μοντέλο από
   φωτογραφίες) δεν μπορεί να τρέξει αληθινά — χτίζω γύρω του με
   προσομοίωση, όπως σε κάθε άλλο εργαλείο αυτή τη σεζόν.**
2. **Έγκριση: Meshy και για τα δύο επίπεδα, όχι Tripo, όχι TRELLIS**, για
   τους τρεις λόγους πάνω — αν προτιμάς το Tripo ή θέλεις και τα δύο
   μέσω router εξαρχής, πες το και αλλάζει πριν χτιστεί το Κομμάτι 3.
3. **Δεν ζητάω κλειδί Tripo τώρα** — μένει στο πίσω μέρος για τον router
   (Κομμάτι 6) αν ποτέ χρειαστεί δεύτερος πάροχος. Αν θέλεις να το
   ζητήσω τώρα παράλληλα, πες το.

## Τι μένει να επιβεβαιωθεί ζωντανά (το δίκτυο εδώ δεν το επέτρεψε)

- Ο ακριβής σημερινός αριθμός credits/μοντέλο στο Meshy — η σελίδα API
  και η σελίδα web app διαφωνούν μεταξύ τους.
- Το ακριβές κείμενο των Όρων Χρήσης Meshy/Tripo για ρήτρα ΕΕ/ΕΟΧ —
  καμία βρέθηκε μέσω αναζήτησης, αλλά καμία από τις δύο σελίδες διαβάστηκε
  αυτολεξεί.
- Τα ακριβή όρια μεγέθους αρχείου εισόδου στο API του Meshy (10MB vs
  20MB, δύο σελίδες διαφωνούν).
- Αν η Image-to-3D του Meshy είναι μία κλήση ή έχει preview/refine στάδια
  όπως το Text-to-3D του — επηρεάζει πώς χτίζεται το Πρόχειρο/Τελικό.
- Η απάντηση της Microsoft στο GitHub issue #298 του TRELLIS (αν δοθεί
  ποτέ) — θα άλλαζε την αξιολόγηση πάνω αν ξεκαθαρίσει την εμπορική χρήση.
