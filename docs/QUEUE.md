# Ουρά εργασιών

Η σειρά του ιδιοκτήτη, `docs/BUILD-SPECS.md` ενότητα 6, Γ2 (2026-10-05).
Περιέχει ό,τι απομένει από όλες τις προδιαγραφές. Η λίστα από την οποία
βγαίνει, σημείο προς σημείο, με κατάσταση και τι μπλοκάρει, είναι το
`docs/REMAINING.md`. Οι γραμμές κρατούν τα αναγνωριστικά που είχαν
(Α.x, D.x, E.x, 1.x–6.x), ώστε οι παραπομπές από τα άλλα έγγραφα να
δείχνουν ακόμα κάπου· οι νέες παίρνουν γράμμα της ομάδας τους.

- Κατάσταση γραμμής: **εκκρεμεί** · **σε εξέλιξη** · **φτιαγμένο,
  αδοκίμαστο σε browser** · **έτοιμο** · **μπλοκαρισμένο**.
- «Έτοιμο» = λειτουργικό με τον ορισμό του BUILD-SPECS 4.1: όλα τα
  σενάρια ως tests, αποθηκευμένο στη Βιβλιοθήκη, και το είδα σε browser
  με πραγματικό λογαριασμό. Μέχρι το NEEDS 2, ό,τι τελειώνει γράφεται
  «φτιαγμένο, αδοκίμαστο σε browser».
- Κάθε νέο feature περνά από τον έλεγχο του Μέρους Α (ποιος βλέπει τι,
  τι φτάνει στον browser, χρέωση στον server, περιεχόμενο ως δεδομένα)
  πριν κλείσει. Ένα branch και ένα pull request ανά γραμμή.
- Τα μπλοκαρισμένα: `docs/NEEDS-FROM-ELIAS.md`. Ημερολόγιο:
  `docs/PROGRESS.md`. Ενημερώνεται στο ίδιο commit με τη δουλειά (CLAUDE.md).
