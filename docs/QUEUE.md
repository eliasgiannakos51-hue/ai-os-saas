# Ουρά εργασιών

Η σειρά του ιδιοκτήτη (2026-10-04), που καλύπτει όλο το
`docs/BUILD-SPECS.md` και το `docs/v6-master.md`. Κάθε γραμμή έχει
κατάσταση (**εκκρεμεί** · **σε εξέλιξη** · **έτοιμο** · **μπλοκαρισμένο**)
και παραπομπή στην ενότητα του BUILD-SPECS. Η ενότητα 1 του BUILD-SPECS
ισχύει για όλες.

- «Έτοιμο» = περνούν όλα τα σενάρια ως αυτόματα tests ΚΑΙ το είδα σε
  browser («ΤΡΟΠΟΣ ΛΕΙΤΟΥΡΓΙΑΣ» §8). Σε αυτό το environment δεν
  υπάρχει ακόμα λογαριασμός δοκιμής, άρα μέχρι τότε ό,τι τελειώνει
  γράφεται «φτιαγμένο, αδοκίμαστο σε browser».
- «Υπάρχει ήδη» = ό,τι βρήκα στον κώδικα 2026-10-04. Δεν ξαναχτίζεται·
  συμπληρώνεται.
- Τα μπλοκαρισμένα: τι χρειάζεται, στο `docs/NEEDS-FROM-ELIAS.md`.
  Ημερολόγιο: `docs/PROGRESS.md`. Κατάσταση εργαλείων:
  `docs/TOOLS-STATUS.md`.

Ενημερώνεται στο ίδιο commit με τη δουλειά, ποτέ μετά (CLAUDE.md).
