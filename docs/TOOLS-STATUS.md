# Κατάσταση εργαλείων

Μέτρο: τα σενάρια του `docs/BUILD-SPECS.md`, συν η ενότητα 1 του (κοινές
απαιτήσεις). **Πλήρες** μόνο όταν περνούν όλα τα σενάρια ως αυτόματα
tests και το εργαλείο έχει φανεί να δουλεύει σε browser («ΤΡΟΠΟΣ
ΛΕΙΤΟΥΡΓΙΑΣ» §2 και §8 στο `docs/CONTEXT.md`). Αλλιώς **beta**, με το
τι λείπει.

**Στις 2026-10-04 κανένα εργαλείο δεν είναι «πλήρες» και κανένα σενάριο
του BUILD-SPECS δεν έχει ακόμα δικό του test.** Η στήλη «περνούν» είναι
γι' αυτό 0 παντού: δεν σημαίνει ότι τίποτα δεν δουλεύει, σημαίνει ότι
κανένα σενάριο δεν έχει αποδειχθεί με τον τρόπο που ορίζει το
BUILD-SPECS. Ό,τι δουλεύει σήμερα είναι στη στήλη «υπάρχει».

Κοινά κενά για όλα (BUILD-SPECS 1): δεν υπάρχει ακόμα μητρώο, κοινός
σκελετός, Βιβλιοθήκη, ετικέτες μνήμης στις απαντήσεις, ούτε οι έξι
καταστάσεις οθόνης ως κοινό component (ΦΑΣΗ 1 στο `docs/QUEUE.md`).
