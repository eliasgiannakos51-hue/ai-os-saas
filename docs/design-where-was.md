# Πού ήταν, πού είναι τώρα

BUILD-SPECS 2.4, σενάριο 15: «Καμία υπάρχουσα λειτουργία δεν χάνεται. Ό,τι
έφυγε από το sidebar είναι στο All tools και στο ⌘K».

Η στήλη «Πού ήταν» είναι το `main` όπως ήταν την 2026-10-04 (commit
`3d81a683`, ό,τι τρέχει σήμερα στην παραγωγή). Η στήλη «Πού είναι» είναι
το design (branch `design-d`, βήματα D.1–D.10). Το `npm run gates`
ελέγχει τις διαδρομές του πίνακα. Οι γραμμές του All tools ελέγχονται
από τα `sidebar-structure.test.mjs` και `all-tools.test.mjs`.

## Το sidebar

| Στοιχείο | Πού ήταν | Πού είναι τώρα |
|---|---|---|
| Λογότυπο | πορτοκαλί σφαίρα με δακτύλιο και «ionexa ai» | η γη (στατική) και η λέξη IONEXA |

| Recent | τα 5 τελευταία που άνοιξες, στον browser | τα εργαλεία με 2 χρήσεις σε 30 μέρες, το πολύ 5, καρφίτσωμα και αφαίρεση, στον λογαριασμό |
| Integrations | μπλοκ Ρυθμίσεων στο κάτω μέρος του sidebar | All tools (μπλοκ Ρυθμίσεων, τελευταίο) και ⌘K |
