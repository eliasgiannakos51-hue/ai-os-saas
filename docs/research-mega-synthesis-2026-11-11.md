### ΣΤ2. Ασφάλεια Payments

**Ήδη φτιαγμένα:**
- ✅ Stripe handles PCI compliance (card data never touches our servers)
- ✅ Deny-all RLS on payments tables
- ✅ Service-role only access to payment operations
- ✅ Rate limiting on all payment endpoints (30/hr per IP on public)
- ✅ CSRF protection on all API routes

**Πρέπει να χτιστούν:**
1. **Fraud scoring** — Stripe Radar integration (velocity, geo-mismatch, amount flags)

3. **3D Secure** — enforce on high-risk transactions
4. **IP block lists** — known fraudulent sources
5. **Amount thresholds** — flag large first purchases (>$500)
6. **Duplicate detection** — same card in multiple accounts

### ΣΤ3. Ασφάλεια Agents

**Ήδη φτιαγμένα:**
- ✅ Approval center (send/publish/spend) — τίποτα μη-αναστρέψιμο χωρίς έγκριση
- ✅ Credit cap per agent — σταματά αν ξεπεράσει όριο
- ✅ Agent text sanitization — αφαιρεί injection attempts
- ✅ 24h TTL on approvals — expired approvals rejected

**6 Guardrails για agents με πληρωμές** (βάσει Stripe/Mastercard/Visa industry analysis):
1. **Spending limits and caps** — per-transaction max, session cap, daily total
2. **Allowlisting** — permitted payment destinations only
3. **Approval workflows** — small=auto, medium=notify, large=human
4. **Policy engine** — DENY always wins
5. **Audit trail** — every financial action logged with agent ID
6. **Rollback** — reverse within time window
